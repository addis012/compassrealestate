COMPASS PROPERTIES WEBSITE

Files:
- index.html: responsive single-page website (Amharic-first with English SEO terms)
- assets/compass-properties-logo.jpg: supplied company logo
- robots.txt: search engine crawl instructions
- sitemap.xml: initial sitemap

BEFORE PUBLISHING:
1. Replace every occurrence of https://YOUR-DOMAIN.com with the real domain.
2. Replace [ADD OFFICIAL PHONE NUMBER] with the company's real phone number.
3. Replace [ADD OFFICIAL EMAIL] and ADD-EMAIL@example.com with the real company email.
4. Verify all prices, discounts, areas, facilities, construction status and handover timelines against current signed project information.
5. Upload all files and the assets folder into public_html on cPanel.
6. Enable HTTPS, then submit https://YOUR-DOMAIN.com/sitemap.xml in Google Search Console.

Ranking is not guaranteed. Google Ads approval depends on the actual business, landing page, claims and advertising policies.
